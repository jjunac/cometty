# AGENTS.md

Single-binary Rust terminal emulator (`cometty`). Edition 2024. CI runs
`cargo test` + `cargo clippy -- -D warnings` + `cargo fmt --check` (see
`.github/workflows/ci.yml`).

## Commands

- `cargo test` — 384 unit tests in `grid`/`term`/`input`/`config`/`tabbar`/`icon`/`app::geometry`/`app::settings`/`app::logs`/`app::persistence`/`app::search`/`app::redraw`/`app::links`/`app::tab`/`procinfo`/`scrollbar`/`selection`/`search`/`links`/`theme`/`logbuf`/`logging`/`pty::input`/`renderer` (incl. `renderer::blocks`/`renderer::log_ui`/`renderer::search_ui`/`renderer::settings_ui`); runs instantly, no services needed.
- `cargo run` — launches GUI window (needs display + GPU surface). Do not run headless; prefer `cargo test` / `cargo check`.
- `cargo clippy -- -D warnings` and `cargo fmt --check` — no configs committed; keep code warning- and rustfmt-clean.

## Architecture (`src/`)

- `main.rs` — thin winit `ApplicationHandler`: window create, egui pre-dispatch, then delegates to `app::*`. Also parses `--theme NAME` / `--list-themes` / `--help`. Builds the event loop first so `logging::install` can capture config-load warnings and wake the loop for the log panel.
- `app/` — event/state split from the old `window_event` god function: `mod` (App state + `UserEvent`), `keyboard` (copy/paste shortcuts, Shift+scroll, PTY send), `mouse` (drag-select, double-click word via `DOUBLE_CLICK_MS`, wheel, link click, encoded-motion dedup), `redraw` (resize apply → PTY drain → `Renderer::render`), `clipboard` (selection copy/paste + `OSC 52` policy + one-pass paste normalization), `links` (hint modifier, hover detection, open), `pty_io` (`drain_pty`, `apply_resize`, input notices), `selection_view`, `tab` (tab model + `[tabbar] title_format` interpolation; `refresh_title` caches the foreground pgid's command and the shell's cwd, re-queried only on output; selection rebase across eviction), `settings` (panel state + diff/reset helpers), `persistence` (bounded ordered config-save worker + debounce), `logs` (log-panel state + `is_logs_toggle`), `search` (per-tab find-bar state + `is_search_toggle` + row-identity projection), `geometry` (`clamp_grid_size` single source of truth for all resize/PTY clamps). Resize is deferred via `pending_resize` and applied in `RedrawRequested` (`apply_resize`: renderer → terminal → pty).
- `logbuf.rs` / `logging.rs` — in-app log ring + global logger. `LogBuffer` is a `VecDeque<Arc<LogEntry>>` bounded by entry count **and** a derived byte budget, with stable entry IDs/generation, `dropped` accounting and per-message truncation; `LogIndex` caches filtered **IDs** incrementally in ≤2 ms slices outside the ring lock, drops evicted IDs, acquires only visible entries per paint, and performs a full snapshot only for explicit Copy. `logging::install` replaces `env_logger::init()` and fans out to **two independent filters**: stderr keeps `RUST_LOG` (default `error`), the buffer records by **directives** (`env_filter`) — `[log] filter`, else `cometty=<level>,warn` — so dependency debug/trace noise (`naga::*`, `cosmic_text::*`) is excluded while their warnings still land in the panel. `max_level` = the more verbose of the two; rejected directives keep the previous filter and are surfaced in the panel header (not logged per keystroke while typing). Records wake the event loop at most once per coalesced batch while the panel is open (`set_wake_enabled`, `acknowledge_wake`), flipped by `LogsPanel`.
- `grid/` — terminal state split by concern: `mod` (struct + `new`/`resize` + accessors + tests), `cell` (Cell/Pen/Cursor + blank/erase cells), `row` (stable logical row identity + revision, independent of screen position or recycled storage), `history` (lazy width projection + byte budget + recycled eviction), `link` (interned OSC 8 URI table + current-link state; `Cell.hyperlink: Option<u16>`, capped by count/URI length/total bytes), `scroll` (scrollback + view offsets + borrowed `global_line` for search), `edit` (write/erase/insert/delete), `style` (SGR), `alt` (alt buffer + mode flags). 10k-line scrollback, monotonic `version` plus `content_version` (bumped only when cells change; view-only scrolls use `bump_view`, so content caches stay valid). Wrap uses pending-wrap protocol (`put_char` leaves `cursor.x == cols`; `Terminal::print` resolves on next char). Renderer skips rebuild when `grid.version` unchanged.
- History rows keep their stored cell buffers across width changes. Each resize updates one compact `Projection` per cohort (rows admitted at the same width): retained prefix, structural-padding runs, destructive-shrink edge color, and wide-edge repair. Rendering/search/links/copy consume the same `RowView`, so hidden text cannot reappear after a shrink and no per-row resize journal or cell copies are needed. A per-tab `scrollback_bytes` budget (default 128 MiB) bounds cell capacity, cluster tails, deque capacity and projections; `history_dropped` counts rows leaving the global-front line sequence (retained or discarded). At the cap, the evicted row buffer is BCE-filled and reused for the new bottom row; recycled storage always gets a new logical row id. `scrollback_lines=0` or `scrollback_bytes=0` retains no history. `max_cells` (default 1024²) and the PTY `u16` limit are enforced by `app::geometry::clamp_grid_size` for window, Grid and PTY dimensions.
- `term.rs` — `vte::Perform` impl feeding `Grid`. `feed()` swaps `Parser` out via `mem::replace` to satisfy borrow checker — keep that pattern. Supports CSI `A-H`, `J/K/L/M/S/T`, `s/u`, `E/F/G/d`, private modes `?25` (cursor), `?2004` (bracketed paste), `?47/?1047/?1048/?1049` (alt screen), ESC `M/7/8/c`, SGR `38;5`/`48;5` + `38;2`/`48;2` truecolor. Every OSC is logged at `debug` (`osc_summary`: number, standard name, `unhandled` marker, truncated + control-escaped payload, terminator) so the panel shows sequence types cometty ignores today; OSC 0/1/2 titles (`osc_title`), OSC 7 `file://` cwd (`osc_cwd`, percent-decoded; feeds `$cwd` alongside the kernel query), OSC 8 hyperlinks (`osc_hyperlink`, grid-interned ids) and OSC 52 clipboard requests (`osc_clipboard`, base64 → `ClipboardOp` queue drained by the app; payload contents are redacted in the log) are applied over the shared `osc_parts` splitter. The bell is ignored. Other CSI intermediates are ignored.
- `procinfo.rs` — best-effort `command(pid)` / `cwd(pid)` for tab labels: `proc_pidpath`/`proc_pidinfo(PROC_PIDVNODEPATHINFO)` on macOS, `/proc/<pid>/{exe,cwd}` on Linux, `None` elsewhere. `shorten_home` rewrites a leading `$HOME` to `~`. Never fatal: callers fall back to the shell's OSC 7 or an empty variable.
- `pty.rs` — `portable-pty`, shell from `$SHELL` (fallback `/bin/bash`), `TERM=xterm-256color`, cwd `$HOME`. Two detached threads (read 8KB loop / write loop). `PtyEvent::Exit` fires on EOF/read-error. Size clamps reuse `app::geometry::clamp_grid_size`. `foreground_pgid()` wraps `MasterPty::process_group_leader()` (`tcgetpgrp`) and `shell_pid()` exposes the spawned child's pid; both feed tab labels. UI→PTY input (`pty/input.rs`) is nonblocking and byte-accounted (16 MiB, including allocation capacity and in-flight writes): overflow/oversized bulk input is rejected atomically and surfaced as a passive notice, never silently overriding focus/IME; parser replies keep reserved headroom and pause that tab's output drain until writer progress wakes the loop. Normal input preserves FIFO; paste is written as one transaction in 8 KiB chunks.
- `search.rs` — pure find model behind the find bar (`Cmd+F` on macOS, `Ctrl+F` elsewhere): smart-case (`is_smart_case`: any uppercase char = case-sensitive) non-overlapping matches over cluster-lead text with a byte→column span table (wide clusters highlight whole, trailing blanks are skipped, alt screen searches visible rows only), plus view projection (`SearchView`/`Hit`), `pick_initial`, `step` wrap-around, and `reveal_offset` (minimal scroll). `app::search::SearchPanel` caches `find_matches` keyed to `grid.content_version`; the projection stores captured row IDs and shifts line indices by `grid.history_dropped`, so a throttled refresh cannot reveal or highlight recycled storage.
- `links.rs` — pure hyperlink model behind the hint underlines + click-to-open: `HintView` projects per-row runs (OSC 8 link ids first — detection never double-underlines a linked cell — then `detect_urls` hits: allowlisted schemes `http/https/ftp/mailto` (`file` is refused so untrusted output can't open local paths) plus `www.` (normalized to `https://` at open), word-boundary + trailing-punctuation trimming, byte→column spans for wide clusters), and `open_command` builds the opener argv per platform (`open`/`xdg-open` exec directly with no shell; Windows `cmd /C start` refuses URIs with cmd metacharacters; allowlisted + control-stripped URIs only). Detection is per visual row: the grid records no soft-wrap flag, so a wrapped URL is only detected on its rows. `app::links` owns the modifier check (`auto` = Cmd on macOS, Ctrl elsewhere), hover detection, and `update_link_cursor`; `app::tab::Tab::link_hints` caches the view keyed to `grid.version` + `detect_urls`.
- `renderer/` — wgpu + glyphon/cosmic-text split from the old `render` god function: `mod` (struct + `new` + thin `render` orchestrator), `text` (buffer shaping + explicit layout), `background` (`BgVertex`/`BG_SHADER`, `paint_bg` with reused `bg_scratch` buffer), `blocks` (cell-perfect geometry for Unicode block elements U+2580..U+259F), `overlay` (egui scrollbar/tab-bar chrome + panel hookup + passive input notice), `search_ui` (floating find bar: query field, counter, next/prev/close; the next/prev chevrons are **painted** because egui's bundled fonts have no U+2191/U+2193), `settings_ui` (settings panel widgets), `log_ui` (log viewer window: virtualized rows via `ScrollArea::show_rows`, display-only level/text filter backed by `LogIndex`). Fixed metrics with `cell_width = font_size * 0.602` (see `scaled_metrics`). All bg/shape rects snap to whole device pixels with shared edges (`snap_col_edges`/`snap_row_edges`/`snap_rect`) so neighbouring cells tile without seams. Block elements are painted as rects (not font glyphs, whose line box is shorter than the cell) and their cells shape a space instead (`text::build_buffer_lines`); shades U+2591..U+2593 keep font glyphs. Bg quads via custom WGSL pipeline; text via `TextRenderer`. Recovers from lost/outdated surface by reconfiguring. `cols_for_width`/`rows_for_height` + `app::geometry` drive PTY resize.
- `input.rs` — pure `map_key()` (unit-testable) + `key_to_bytes()` wrapper. Ctrl+letter synthesizes `0x01–0x1A`; Enter→`\r`, Backspace→`0x7F`; releases return `None`. `KeyEvent` can't be struct-constructed (private fields), so tests target `map_key` only.

## Gotchas

- GUI binary: `cargo run`/`cargo build` need windowing/GPU; verification in headless sessions = `cargo test` + `cargo check`.
- `grid::cell()`, `pen()`, `scrollback_len()` are `#[allow(dead_code)]` test/inspection helpers — do not remove. Same for `Renderer::set_theme` (future runtime switching) and `term` inspectors.
- Erase uses BCE semantics: `ED/EL/clear` + `IL/DL`/scroll fill use `erase_cell()` (current pen bg, default fg/attrs); `blank_cell()` is only for structural fills (resize growth, fresh alt buffer).
- Hyperlinks: the active OSC 8 link is grid state *outside* `Pen` — `SGR 0` must not clear it (only `OSC 8 ; ; ST` or `ESC c` do), and cells only carry an interned `Option<u16>` id so scrollback rows stay small. Hint underlines are painted in `paint_bg` from `HighlightCtx.links` (never gate them on `grid.version`: the feature is modifier-driven, so `main.rs` requests a redraw when the modifier flips). Click-to-open is checked **before** mouse reporting so links stay clickable inside TUIs, and the matching release is swallowed via `App::link_press`.
- macOS fullscreen stripes (Intel Iris Plus/Metal): a drawable sized exactly like the display makes the driver paint the *cleared* background as vertical stripes (`wgpu#3415`); only the terminal bg is affected (painted geometry/egui chrome stay correct). `renderer::shrink_fullscreen_surface` crops the surface 1px when `app::geometry::is_fullscreen_like` (window flag or display-sized window) says the drawable is display-sized. The 1px delta is deliberate — don't "fix" it.
- Log panel: panel state (`app::logs::LogsPanel`) is display-only; recording is directive-based (`[log] level`/`[log] filter`, target-scoped — a bare level would let `naga`/`cosmic_text` debug spam in) and independent of stderr's `RUST_LOG`. The egui window must not lock the ring while closed, and row content must never exceed the fixed row height (`ScrollArea::show_rows` would drift). Filtering is incremental by ID outside the lock in ≤2 ms slices; only visible entries are fetched for paint, and Copy takes a complete snapshot on request. The `Ctrl/Cmd+Shift+L` check in `app::keyboard` must stay **before** the `settings.open` early-return, and the panel deliberately does *not* swallow shell keys (only egui's `consumed` flag does, when the filter box has focus).
- History: do not reintroduce eager per-row width rewrites. `RowView` is the only projection consumed by render/search/links/copy, and shrink must remain destructive (cut prefix, no resurrection on regrow). Structural padding uses the theme at growth time; existing cells keep their old colors. `history_dropped` counts every row leaving the global-front sequence (including rows discarded by zero/byte caps, not just retained scrollback evictions) and drives selection/search line rebasing. Recycled row storage must get a new id, and `history_bytes` must include capacities, extras and projections. Never replace BCE erase fills with structural blank fills.
- Input queue: admission is byte-accounted and nonblocking; blocked parser replies must keep reserved headroom and re-arm the tab on writer progress. Do not block the UI thread, drop keyboard bytes silently, split bracketed-paste transactions, or let the notice overlay become focusable (Tab/IME ownership must stay with the terminal).
- Settings persistence: `ConfigSaver` is the only writer; edits debounce, shutdown flushes, and stale generations must not overwrite/report over newer ones. Keep the atomic temp-file/rename save path and GUI-wins precedence. `Renderer::apply_config` must not flush shaping caches for non-font settings.
- Find bar: `Cmd+F` on macOS (Ctrl+F on Linux/Windows; `[input] search_key`/`search_ctrl`/`search_super` override) opens/re-focuses (never closes; `Esc`/`×` do) and sits **after** the `settings.open` early-return. `Enter`/`Shift+Enter`/`F3`/`Shift+F3` are handled before the `egui_consumed` check so the query field can keep focus (`TextEdit::return_key(None)` stops egui from dropping it) while the shell never sees those keys; typing goes through egui, and keys not consumed by it still reach the shell (log-panel semantics). While `focus_requested` is set (open frame, before egui grants focus) printable keys are swallowed so they can't hit the shell. `search_ui` must surrender the field's focus when the bar is closed, or egui's `consumed` would eat shell keys with no widget on screen. Matches are cached against `grid.content_version` (not `version`) and re-picked only on query/open change — a background refresh must never scroll. The bar's painted rect is stored on the renderer (`over_search_bar`) so presses/wheel on it aren't treated as terminal selection; `app::tab::Tab` owns the per-tab panel, invalidated on tab switch (two tabs can share a content version).
- Tab labels: `[tabbar] title_format` interpolation never strips or rewrites the user's literal separators — missing variables just expand to empty; only an all-empty render falls back to `Tab N`. `$command` is the foreground **process-group leader** (kernel query), so a pipeline reports its first command and a prompt reports the shell. `$cwd` never follows the job: while a job owns the tty a *live* shell `OSC 7` wins (an integrated `ssh`/nested shell or a file manager reporting as it runs; reports older than the last prompt are stale leftovers and ignored — `app::tab::osc7_is_live`), else the shell process's kernel cwd; at the prompt the live kernel cwd wins so a stale `OSC 7` can't stick (see `app::tab::preferred_cwd`). Both are cached per tab and re-queried in `drain_pty` after output only — keep syscalls off the render path, and don't seed at spawn (the child may not have exec'd yet, which would report cometty's own image).
- egui repaint scheduling: the loop is reactive (PTY output / blink), so egui only animates if its requests are forwarded. Input events must honor `egui_winit::EventResponse::repaint` (`RedrawRequested` excluded — egui always reports `repaint: true` for it, so honoring it loops), and continuous animations come from `FullOutput.viewport_output[ROOT].repaint_delay` (`paint_overlay` → `RenderOutput` → `App::egui_repaint_at`, woken by `about_to_wait`'s `WaitUntil`; `Duration::MAX` = idle, schedule nothing). Dropping either makes egui step once per `blink_ms` (and `stable_dt` clamps to ~1/60 s, so a 0.1 s hover fade takes seconds). `scrollbar.update` must stay **before** `end_pass` so its repaint request lands in that frame's `repaint_delay`.
- egui keyboard focus: `egui-winit` marks every `Tab` consumed (focus navigation), so forwarding `Tab` to egui strands focus in chrome and starves the PTY of all keys until the next grid click. `Tab` bypasses egui while `App::terminal_owns_keyboard` (no settings panel, no pending find focus, no text field focused); tab-strip/scrollbar/chevrons use non-focusable `Sense::CLICK`/`DRAG` consts (`Sense::click()` is focusable) and grid presses surrender stale focus. Dead-key commits arrive as `WindowEvent::Ime::Commit` (no `KeyboardInput`), forwarded to the PTY under the same ownership rule — and the renderer re-asserts window IME whenever no egui text field owns the keyboard (`renderer::terminal_ime_step`), because egui disables IME when the find bar/log filter/settings input loses focus and macOS dead keys otherwise vanish before any event exists.
