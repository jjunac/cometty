# AGENTS.md

Single-binary Rust terminal emulator (`cometty`). Edition 2024. CI runs
`cargo test` + `cargo clippy -- -D warnings` + `cargo fmt --check` (see
`.github/workflows/ci.yml`).

## Commands

- `cargo test` — 255 unit tests in `grid`/`term`/`input`/`app::geometry`/`app::settings`/`app::logs`/`app::search`/`app::tab`/`procinfo`/`scrollbar`/`selection`/`search`/`theme`/`logbuf`/`logging`/`renderer` (incl. `renderer::blocks`/`renderer::log_ui`/`renderer::search_ui`/`renderer::settings_ui`); runs instantly, no services needed.
- `cargo run` — launches GUI window (needs display + GPU surface). Do not run headless; prefer `cargo test` / `cargo check`.
- `cargo clippy -- -D warnings` and `cargo fmt --check` — no configs committed; keep code warning- and rustfmt-clean.

## Architecture (`src/`)

- `main.rs` — thin winit `ApplicationHandler`: window create, egui pre-dispatch, then delegates to `app::*`. Also parses `--theme NAME` / `--list-themes` / `--help`. Builds the event loop first so `logging::install` can capture config-load warnings and wake the loop for the log panel.
- `app/` — event/state split from the old `window_event` god function: `mod` (App state + `UserEvent`), `keyboard` (copy/paste shortcuts, Shift+scroll, PTY send), `mouse` (drag-select, double-click word via `DOUBLE_CLICK_MS`, wheel), `redraw` (resize apply → PTY drain → `Renderer::render`), `clipboard`, `pty_io` (`drain_pty`, `apply_resize`), `selection_view`, `tab` (tab model + `[tabbar] title_format` interpolation; `refresh_title` caches the foreground pgid's command/cwd, re-queried only on output), `settings` (panel state + diff/reset helpers), `logs` (log-panel state + `is_logs_toggle`), `search` (per-tab find-bar state + `is_search_toggle`), `geometry` (`MAX_DIM`/`compute_grid_size` single source of truth for all resize/PTY clamps). Resize is deferred via `pending_resize` and applied in `RedrawRequested` (`apply_resize`: renderer → terminal → pty).
- `logbuf.rs` / `logging.rs` — in-app log ring + global logger. `LogBuffer` is a `VecDeque<Arc<LogEntry>>` bounded by entry count **and** a derived byte budget, with `dropped` accounting and per-message truncation; `logging::install` replaces `env_logger::init()` and fans out to **two independent filters**: stderr keeps `RUST_LOG` (default `error`), the buffer records by **directives** (`env_filter`) — `[log] filter`, else `cometty=<level>,warn` — so dependency debug/trace noise (`naga::*`, `cosmic_text::*`) is excluded while their warnings still land in the panel. `max_level` = the more verbose of the two; rejected directives keep the previous filter and are surfaced in the panel header (not logged per keystroke while typing). Records wake the event loop via the stored winit proxy only while the panel is open (`set_wake_enabled`, flipped by `LogsPanel`).
- `grid/` — terminal state split by concern: `mod` (struct + `new`/`resize` + accessors + tests), `cell` (Cell/Pen/Cursor + blank/erase cells), `scroll` (scrollback + view offsets + borrowed `global_line` for search), `edit` (write/erase/insert/delete), `style` (SGR), `alt` (alt buffer + mode flags). 10k-line scrollback, monotonic `version` plus `content_version` (bumped only when cells change; view-only scrolls use `bump_view`, so content caches stay valid). Wrap uses pending-wrap protocol (`put_char` leaves `cursor.x == cols`; `Terminal::print` resolves on next char). Renderer skips rebuild when `grid.version` unchanged.
- `term.rs` — `vte::Perform` impl feeding `Grid`. `feed()` swaps `Parser` out via `mem::replace` to satisfy borrow checker — keep that pattern. Supports CSI `A-H`, `J/K/L/M/S/T`, `s/u`, `E/F/G/d`, private modes `?25` (cursor), `?2004` (bracketed paste), `?47/?1047/?1048/?1049` (alt screen), ESC `M/7/8/c`, SGR `38;5`/`48;5` + `38;2`/`48;2` truecolor. Every OSC is logged at `debug` (`osc_summary`: number, standard name, `unhandled` marker, truncated + control-escaped payload, terminator) so the panel shows sequence types cometty ignores today; OSC 0/1/2 titles (`osc_title`) and OSC 7 `file://` cwd (`osc_cwd`, percent-decoded, kernel cwd wins) are applied over the shared `osc_parts` splitter. The bell is ignored. Other CSI intermediates are ignored.
- `procinfo.rs` — best-effort `command(pid)` / `cwd(pid)` for tab labels: `proc_pidpath`/`proc_pidinfo(PROC_PIDVNODEPATHINFO)` on macOS, `/proc/<pid>/{exe,cwd}` on Linux, `None` elsewhere. `shorten_home` rewrites a leading `$HOME` to `~`. Never fatal: callers fall back to OSC 7 or an empty variable.
- `pty.rs` — `portable-pty`, shell from `$SHELL` (fallback `/bin/bash`), `TERM=xterm-256color`, cwd `$HOME`. Two detached threads (read 8KB loop / write loop). `PtyEvent::Exit` fires on EOF/read-error. Size clamps reuse `app::geometry::{MIN_DIM, MAX_DIM}`. `foreground_pgid()` wraps `MasterPty::process_group_leader()` (`tcgetpgrp`) for tab labels.
- `search.rs` — pure find model behind the `Ctrl+F` bar: smart-case (`is_smart_case`: any uppercase char = case-sensitive) non-overlapping matches over cluster-lead text with a byte→column span table (wide clusters highlight whole, trailing blanks are skipped, alt screen searches visible rows only), plus view projection (`SearchView`/`Hit`), `pick_initial`, `step` wrap-around, and `reveal_offset` (minimal scroll). `app::search::SearchPanel` caches `find_matches` keyed to `grid.content_version`.
- `renderer/` — wgpu + glyphon/cosmic-text split from the old `render` god function: `mod` (struct + `new` + thin `render` orchestrator), `text` (buffer shaping + explicit layout), `background` (`BgVertex`/`BG_SHADER`, `paint_bg` with reused `bg_scratch` buffer), `blocks` (cell-perfect geometry for Unicode block elements U+2580..U+259F), `overlay` (egui scrollbar/tab-bar chrome + panel hookup), `search_ui` (floating find bar: query field, counter, next/prev/close; the next/prev chevrons are **painted** because egui's bundled fonts have no U+2191/U+2193), `settings_ui` (settings panel widgets), `log_ui` (log viewer window: virtualized rows via `ScrollArea::show_rows`, display-only level/text filter). Fixed metrics with `cell_width = font_size * 0.602` (see `scaled_metrics`). All bg/shape rects snap to whole device pixels with shared edges (`snap_col_edges`/`snap_row_edges`/`snap_rect`) so neighbouring cells tile without seams. Block elements are painted as rects (not font glyphs, whose line box is shorter than the cell) and their cells shape a space instead (`text::build_buffer_lines`); shades U+2591..U+2593 keep font glyphs. Bg quads via custom WGSL pipeline; text via `TextRenderer`. Recovers from lost/outdated surface by reconfiguring. `cols_for_width`/`rows_for_height` + `app::geometry` drive PTY resize.
- `input.rs` — pure `map_key()` (unit-testable) + `key_to_bytes()` wrapper. Ctrl+letter synthesizes `0x01–0x1A`; Enter→`\r`, Backspace→`0x7F`; releases return `None`. `KeyEvent` can't be struct-constructed (private fields), so tests target `map_key` only.

## Gotchas

- GUI binary: `cargo run`/`cargo build` need windowing/GPU; verification in headless sessions = `cargo test` + `cargo check`.
- `grid::cell()`, `pen()`, `scrollback_len()` are `#[allow(dead_code)]` test/inspection helpers — do not remove. Same for `Renderer::set_theme` (future runtime switching) and `term` inspectors.
- Erase uses BCE semantics: `ED/EL/clear` + `IL/DL`/scroll fill use `erase_cell()` (current pen bg, default fg/attrs); `blank_cell()` is only for structural fills (resize growth, fresh alt buffer).
- macOS fullscreen stripes (Intel Iris Plus/Metal): a drawable sized exactly like the display makes the driver paint the *cleared* background as vertical stripes (`wgpu#3415`); only the terminal bg is affected (painted geometry/egui chrome stay correct). `renderer::shrink_fullscreen_surface` crops the surface 1px when `app::geometry::is_fullscreen_like` (window flag or display-sized window) says the drawable is display-sized. The 1px delta is deliberate — don't "fix" it.
- Log panel: panel state (`app::logs::LogsPanel`) is display-only; recording is directive-based (`[log] level`/`[log] filter`, target-scoped — a bare level would let `naga`/`cosmic_text` debug spam in) and independent of stderr's `RUST_LOG`. The egui window must not lock the ring while closed, and row content must never exceed the fixed row height (`ScrollArea::show_rows` would drift). The `Ctrl/Cmd+Shift+L` check in `app::keyboard` must stay **before** the `settings.open` early-return, and the panel deliberately does *not* swallow shell keys (only egui's `consumed` flag does, when the filter box has focus).
- Find bar: `Ctrl/Cmd+F` opens/re-focuses (never closes; `Esc`/`×` do) and sits **after** the `settings.open` early-return. `Enter`/`Shift+Enter`/`F3`/`Shift+F3` are handled before the `egui_consumed` check so the query field can keep focus (`TextEdit::return_key(None)` stops egui from dropping it) while the shell never sees those keys; typing goes through egui, and keys not consumed by it still reach the shell (log-panel semantics). While `focus_requested` is set (open frame, before egui grants focus) printable keys are swallowed so they can't hit the shell. `search_ui` must surrender the field's focus when the bar is closed, or egui's `consumed` would eat shell keys with no widget on screen. Matches are cached against `grid.content_version` (not `version`) and re-picked only on query/open change — a background refresh must never scroll. The bar's painted rect is stored on the renderer (`over_search_bar`) so presses/wheel on it aren't treated as terminal selection; `app::tab::Tab` owns the per-tab panel, invalidated on tab switch (two tabs can share a content version).
- Tab labels: `[tabbar] title_format` interpolation never strips or rewrites the user's literal separators — missing variables just expand to empty; only an all-empty render falls back to `Tab N`. `$command`/`$cwd` are the foreground **process-group leader** (kernel query), so a pipeline reports its first command and a prompt reports the shell. They are cached per tab and re-queried in `drain_pty` after output only — keep syscalls off the render path, and don't seed at spawn (the child may not have exec'd yet, which would report cometty's own image).
