# AGENTS.md

Single-binary Rust terminal emulator (`cometty`). Edition 2024. CI runs
`cargo test` + `cargo clippy -- -D warnings` + `cargo fmt --check` (see
`.github/workflows/ci.yml`).

## Commands

- `cargo test` — 222 unit tests in `grid`/`term`/`input`/`app::geometry`/`app::settings`/`app::logs`/`scrollbar`/`selection`/`theme`/`logbuf`/`logging`/`renderer` (incl. `renderer::blocks`/`renderer::log_ui`/`renderer::settings_ui`); runs instantly, no services needed.
- `cargo run` — launches GUI window (needs display + GPU surface). Do not run headless; prefer `cargo test` / `cargo check`.
- `cargo clippy -- -D warnings` and `cargo fmt --check` — no configs committed; keep code warning- and rustfmt-clean.

## Architecture (`src/`)

- `main.rs` — thin winit `ApplicationHandler`: window create, egui pre-dispatch, then delegates to `app::*`. Also parses `--theme NAME` / `--list-themes` / `--help`. Builds the event loop first so `logging::install` can capture config-load warnings and wake the loop for the log panel.
- `app/` — event/state split from the old `window_event` god function: `mod` (App state + `UserEvent`), `keyboard` (copy/paste shortcuts, Shift+scroll, PTY send), `mouse` (drag-select, double-click word via `DOUBLE_CLICK_MS`, wheel), `redraw` (resize apply → PTY drain → `Renderer::render`), `clipboard`, `pty_io` (`drain_pty`, `apply_resize`), `selection_view`, `settings` (panel state + diff/reset helpers), `logs` (log-panel state + `is_logs_toggle`), `geometry` (`MAX_DIM`/`compute_grid_size` single source of truth for all resize/PTY clamps). Resize is deferred via `pending_resize` and applied in `RedrawRequested` (`apply_resize`: renderer → terminal → pty).
- `logbuf.rs` / `logging.rs` — in-app log ring + global logger. `LogBuffer` is a `VecDeque<Arc<LogEntry>>` bounded by entry count **and** a derived byte budget, with `dropped` accounting and per-message truncation; `logging::install` replaces `env_logger::init()` and fans out to **two independent filters**: stderr keeps `RUST_LOG` (default `error`), the buffer records by **directives** (`env_filter`) — `[log] filter`, else `cometty=<level>,warn` — so dependency debug/trace noise (`naga::*`, `cosmic_text::*`) is excluded while their warnings still land in the panel. `max_level` = the more verbose of the two; rejected directives keep the previous filter and are surfaced in the panel header (not logged per keystroke while typing). Records wake the event loop via the stored winit proxy only while the panel is open (`set_wake_enabled`, flipped by `LogsPanel`).
- `grid/` — terminal state split by concern: `mod` (struct + `new`/`resize` + accessors + tests), `cell` (Cell/Pen/Cursor + blank/erase cells), `scroll` (scrollback + view offsets), `edit` (write/erase/insert/delete), `style` (SGR), `alt` (alt buffer + mode flags). 10k-line scrollback, monotonic `version`. Wrap uses pending-wrap protocol (`put_char` leaves `cursor.x == cols`; `Terminal::print` resolves on next char). Renderer skips rebuild when `grid.version` unchanged.
- `term.rs` — `vte::Perform` impl feeding `Grid`. `feed()` swaps `Parser` out via `mem::replace` to satisfy borrow checker — keep that pattern. Supports CSI `A-H`, `J/K/L/M/S/T`, `s/u`, `E/F/G/d`, private modes `?25` (cursor), `?2004` (bracketed paste), `?47/?1047/?1048/?1049` (alt screen), ESC `M/7/8/c`, SGR `38;5`/`48;5` + `38;2`/`48;2` truecolor. Every OSC is logged at `debug` (`osc_summary`: number, standard name, `unhandled` marker, truncated + control-escaped payload, terminator) so the panel shows sequence types cometty ignores today; only OSC 0/1/2 titles are applied (`osc_title` over the shared `osc_parts` splitter, used by both). The bell is ignored. Other CSI intermediates are ignored.
- `pty.rs` — `portable-pty`, shell from `$SHELL` (fallback `/bin/bash`), `TERM=xterm-256color`, cwd `$HOME`. Two detached threads (read 8KB loop / write loop). `PtyEvent::Exit` fires on EOF/read-error. Size clamps reuse `app::geometry::{MIN_DIM, MAX_DIM}`.
- `renderer/` — wgpu + glyphon/cosmic-text split from the old `render` god function: `mod` (struct + `new` + thin `render` orchestrator), `text` (buffer shaping + explicit layout), `background` (`BgVertex`/`BG_SHADER`, `paint_bg` with reused `bg_scratch` buffer), `blocks` (cell-perfect geometry for Unicode block elements U+2580..U+259F), `overlay` (egui scrollbar/tab-bar chrome + panel hookup), `settings_ui` (settings panel widgets), `log_ui` (log viewer window: virtualized rows via `ScrollArea::show_rows`, display-only level/text filter). Fixed metrics with `cell_width = font_size * 0.602` (see `scaled_metrics`). All bg/shape rects snap to whole device pixels with shared edges (`snap_col_edges`/`snap_row_edges`/`snap_rect`) so neighbouring cells tile without seams. Block elements are painted as rects (not font glyphs, whose line box is shorter than the cell) and their cells shape a space instead (`text::build_buffer_lines`); shades U+2591..U+2593 keep font glyphs. Bg quads via custom WGSL pipeline; text via `TextRenderer`. Recovers from lost/outdated surface by reconfiguring. `cols_for_width`/`rows_for_height` + `app::geometry` drive PTY resize.
- `input.rs` — pure `map_key()` (unit-testable) + `key_to_bytes()` wrapper. Ctrl+letter synthesizes `0x01–0x1A`; Enter→`\r`, Backspace→`0x7F`; releases return `None`. `KeyEvent` can't be struct-constructed (private fields), so tests target `map_key` only.

## Gotchas

- GUI binary: `cargo run`/`cargo build` need windowing/GPU; verification in headless sessions = `cargo test` + `cargo check`.
- `grid::cell()`, `pen()`, `scrollback_len()` are `#[allow(dead_code)]` test/inspection helpers — do not remove. Same for `Renderer::set_theme` (future runtime switching) and `term` inspectors.
- Erase uses BCE semantics: `ED/EL/clear` + `IL/DL`/scroll fill use `erase_cell()` (current pen bg, default fg/attrs); `blank_cell()` is only for structural fills (resize growth, fresh alt buffer).
- macOS fullscreen stripes (Intel Iris Plus/Metal): a drawable sized exactly like the display makes the driver paint the *cleared* background as vertical stripes (`wgpu#3415`); only the terminal bg is affected (painted geometry/egui chrome stay correct). `renderer::shrink_fullscreen_surface` crops the surface 1px when `app::geometry::is_fullscreen_like` (window flag or display-sized window) says the drawable is display-sized. The 1px delta is deliberate — don't "fix" it.
- Log panel: panel state (`app::logs::LogsPanel`) is display-only; recording is directive-based (`[log] level`/`[log] filter`, target-scoped — a bare level would let `naga`/`cosmic_text` debug spam in) and independent of stderr's `RUST_LOG`. The egui window must not lock the ring while closed, and row content must never exceed the fixed row height (`ScrollArea::show_rows` would drift). The `Ctrl/Cmd+Shift+L` check in `app::keyboard` must stay **before** the `settings.open` early-return, and the panel deliberately does *not* swallow shell keys (only egui's `consumed` flag does, when the filter box has focus).
